# Swiggy Sales Analysis using Excel

## Project Overview

This project analyzes Swiggy sales data using Microsoft Excel to identify sales trends, customer behavior, and business performance.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Excel Formulas
* Data Cleaning
* Data Visualization
* Charts and Dashboard
* Slicers

## Key Analysis

* Total Sales and Revenue
* Order Analysis
* Sales by Category
* Sales Trends
* Customer Analysis
* Performance Comparison

## Dashboard

The interactive Excel dashboard provides a visual summary of important sales and business KPIs.

## Skills Demonstrated

* Data Cleaning
* Data Analysis
* Microsoft Excel
* Pivot Tables
* Data Visualization
* Dashboard Creation
* Business Insights
